## Official evaluation weights

Knowledge Base & Grounding 20%; Assessment Quality 15%; Personalization Effectiveness 20%; User Experience & Demo Video 15%; System Evaluation 15%; Technical Implementation 15%.

## Engineering choices (not PDF requirements)

SQLite stores accounts, private document metadata, quizzes, assessments, and mastery. Passwords use Node scrypt; session tokens are opaque, stored as hashes, and sent via HTTP-only cookies. Every Qdrant query/deletion requires an owner filter. Existing vectors without owner metadata stay inaccessible and must be re-uploaded.
